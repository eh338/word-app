词迹 · GitHub Pages 上传说明（照着点，约 8 分钟）
====================================================

这份说明只讲 GitHub Pages。全程在电脑浏览器里点，不需要装任何软件，
也不需要敲命令。做完之后手机上一个图标，电脑关机也能用。


【第 0 步 · 先保住你现在的数据（重要）】
换网址以后，手机上的学习进度不会自动跟过去：浏览器的本地数据是
按"网址"分开存的。所以请按这个顺序操作：

  1) 先在【旧地址】里打开「设置 → 导出备份」，会下载一个 JSON 文件，存好。
  2) 等新地址能打开后，在新地址「设置 → 导入备份」，选中那个 JSON。
  3) 手机上旧的"词迹"图标删掉，从新地址重新"添加到主屏幕"。

如果旧地址已经打不开（之前的临时隧道已失效），这一步就做不了，
只能从零开始学。以后建议每隔一段时间导出一次备份，存在微信收藏或网盘里。


【第 1 步 · 注册 / 登录 GitHub（约 2 分钟）】
  1. 电脑浏览器打开：https://github.com
  2. 已经有账号：点右上角 "Sign in" 登录，跳到第 2 步。
  3. 没有账号：点右上角 "Sign up" →
     填邮箱、密码、用户名（Username）。
     用户名会出现在你的网址里，只能用英文字母、数字和短横线，
     例如 wangenhui 或 word-app-user。填完点 "Create account"。
  4. GitHub 会往你邮箱发一封验证码邮件，把码填进去完成验证。


【第 2 步 · 新建一个仓库（约 1 分钟）】
  1. 登录后，页面右上角有一个 "+" 号，点它 → 选 "New repository"。
  2. Repository name 填：word-app
     （可以换别的名字，但只能用英文/数字/短横线，记住它，网址里要用）
  3. 下面有三个选项，一定要选 "Public"。
     注意：Private（私有）仓库想开 Pages 要付费，选 Public 才免费。
  4. 下面的 "Add a README file" 等勾选框，全都不用勾。
  5. 点最下面的绿色按钮 "Create repository"。
  6. 创建成功后会跳到一个空仓库页面，标题下面有一行小字
     "…or upload an existing file"，下一步就用它。


【第 3 步 · 把文件传上去（约 2 分钟，最费时间的一步）】
  1. 先把「词迹-app.zip」解压，得到一个文件夹。
     打开文件夹，你应该直接看到 index.html、manifest.json、sw.js、
     app.js、styles.css、data-decks.js、data-articles.js、icons 文件夹、
     还有这份说明。
     ⚠ 不要上传 zip 压缩包本身，GitHub Pages 不会解压它。
     ⚠ 不要在外面再套一层文件夹。
  2. 回到刚才那个空仓库页面，点页面中间那行
     "uploading an existing file"（上传已有文件）。
  3. 页面会变成一个虚线大框，写着 "Drag files here…"。
     两种拖法都行：
       · 直接把整个解压出来的文件夹拖进虚线框（浏览器会自动展开里面的文件）；
       · 或者打开文件夹，按 Ctrl+A 全选所有文件和 icons 文件夹，一起拖进去。
     拖进去后等文件列表出现，文件总大小约 3MB，看网速几十秒。
  4. 确认列表里有 index.html，并且它不在任何子文件夹里
     （如果显示成 "xxx/index.html"，说明多套了一层，删掉重拖）。
  5. 页面拉到最下面，点绿色按钮 "Commit changes"，
     弹出的小窗口里再点一次 "Commit changes" 确认。
  6. 等几秒，你会看到仓库首页列出这些文件，说明上传成功。


【第 4 步 · 打开 Pages 功能（约 1 分钟 + 等 1~3 分钟）】
  1. 仓库页面顶部一排标签里，点 "Settings"（齿轮图标）。
     如果看不到 Settings，说明你没登录，或这个仓库不是你的。
  2. 左侧竖排菜单里找到 "Pages"，点它。
  3. 右边 "Build and deployment" 下面：
       · Source 下拉框选 "Deploy from a branch"
  4. 下面出现 Branch 设置：
       · 第一个下拉框选 "main"
       · 第二个下拉框选 "/ (root)"
       · 点右边 "Save" 按钮。
  5. 等 1~3 分钟，刷新这个页面，顶部会出现一行绿色提示：
       "Your site is live at https://你的用户名.github.io/word-app/"
     这就是你的永久网址。仓库名如果没叫 word-app，把网址里的
     word-app 换成你自己的仓库名。
  6. 想确认进度：点仓库顶部 "Actions" 标签，
     看到一个叫 "pages build and deployment" 的任务，绿勾就是发布好了。
     黄点是在等，红叉是出错（回到第 4 步检查分支和目录有没有选对）。


【第 5 步 · 装到手机桌面（约 1 分钟）】
  1. 用手机浏览器打开上面的网址。别用微信内置浏览器，用 Safari /
     Chrome / 系统自带浏览器。
  2. 第一次打开要下载约 3MB 词库，GitHub Pages 会慢几秒，等 10~30 秒，
     看到选学习阶段的弹窗就成功了。
  3. 加到桌面：
       · iPhone（Safari）：点底部中间的"分享"按钮 → 往下找"添加到主屏幕" → 添加。
       · 安卓（Chrome）：点右上角三个点 → "添加到主屏幕" / "安装应用" → 确认。
  4. 桌面会出现"词迹"图标，点开就是全屏，没有地址栏。之后可以离线用。
  5. 打开新地址后，记得按【第 0 步】把旧备份 JSON 导入进来。


【以后怎么更新】
  仓库页面 → 点 "Add file" → "Upload files" → 把改过的同名文件拖进去 →
  点 "Commit changes"。GitHub Pages 会自动重新发布，等 1~2 分钟生效。
  网址不变，手机上的进度也不会丢（同一个网址，本地数据还在）。


【GitHub Pages 的限制，先说清楚】
  · 仓库必须是 Public（公开），代码谁都能看到；本应用不含任何隐私数据或密钥。
  · 单个文件不能超过 100MB，仓库建议 1GB 以内。
    这个包总共约 1.25MB，完全没压力。
  · 静态托管没有后端，所以下面三项在 GitHub Pages 上用不了：
      × 内置 RSS 新闻源的"拉取最新"
      × 粘贴网页链接后自动提取正文
      × 用 AI 接口自动翻译
    替代办法：
      · 新闻/文章：复制正文，用「粘贴正文」导入；
      · 翻译：导入时把中文译文一起粘贴进去，或先选「暂不翻译」只看英文。
  · 首次打开比商业托管慢几秒；国内访问 github.io 偶尔不稳定，
    打不开时先换网络（比如用手机流量）再试一次。
  · 随包附带的 server.py 是给本机（装 Python）跑服务端功能用的，
    在 GitHub Pages 上不起作用，传不传都不影响使用。


【可选：想要"我改完自动推上去"的高级做法】
  完全不推荐新手走这条，看不懂就跳过，网页上传已经够用了。

  前提：你愿意提供一个 GitHub 的 fine-grained token（细粒度令牌）。
  做法：
    1. GitHub 右上角头像 → Settings → Developer settings
       → Personal access tokens → Fine-grained tokens → Generate new token。
    2. Repository access 选 "Only select repositories"，只勾 word-app 这一个仓库。
    3. Permissions 只勾 "Contents: Read and write"，其它全部不勾。
    4. Expiration 选一个较短的有效期（比如 30 天）。
    5. 生成后复制那串 token（只显示一次）。
  之后可以用 curl 调 GitHub API 直接上传文件，不需要在这台电脑装 git。
  注意：token 等同于密码，不要发到群里或截图公开；用完随时可以在同一页面
  点 "Delete" 撤销。你不提供 token 也完全没问题，走网页上传就行。


【只想先在电脑上试试】
  解压后直接双击 index.html 就能用，不需要服务器，也不需要联网。
  注意：这种双击打开（file://）的方式不能"添加到桌面"，手机上请按上面上传。


【打不开时对照检查】
  · 打开是 404：等 2 分钟再刷新；确认 Settings → Pages 里 Branch 是 main、
    目录是 "/ (root)"，并且仓库根目录真的有 index.html。
  · 页面是白屏 / 一直转圈：确认上传时没漏 data-decks.js 和 data-articles.js，
    这两个是词库和文章数据，缺了会起不来。
  · 手机上没声音：朗读依赖浏览器语音，iOS 要先点一下页面才有声；
    微信内置浏览器常常不支持，换 Safari / Chrome。
